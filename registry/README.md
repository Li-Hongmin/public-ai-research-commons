# Problem Registry

This directory is the discovery layer for official root problems in the Public AI Research Commons.

A registry entry states:

- the public research target;
- where its research records live;
- which external source defines the authoritative problem statement;
- the domain and safety scope.

The registry does **not** decide whether a scientific problem has been solved.

External status and CRL research status are intentionally separate.

Subproblems normally remain records inside a problem repository. A subproblem should be split into another repository only when engineering scale makes that useful.

> Repository boundaries are storage boundaries, not scientific boundaries.
